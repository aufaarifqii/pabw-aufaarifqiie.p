### Token yang saya tetapkan

| Token | Nilai | Untuk apa |
|---|---|---|
| --color-primary | #66c0f4 | judul, tautan, penanda |
| --color-fg | #c7d5e0 | warna teks utama |
| --color-bg | #101822 | latar halaman |
| --color-surface | #1b2838 | latar kartu katalog dan komponen |
| --color-surface-low | #17202d | latar belakang kontainer section dan header |
| --color-border | #212b3b | Pinggiran kotak |
| --color-danger | #ffb4ab | Peringatan kotak belum diisi |
| --color-66c0f4 | #17202d | penanda fokus |
| --radius-md | 0.25rem | sudut tombol dan kartu |
| --space-1 sd --space-6 | 0.25rem - 1.5rem | jarak standar antar elemen |
| --text-sm sd --text-3xl | 0.8125rem - 1.75rem | skala tipografi |
